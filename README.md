# Ejercicios resueltos de bases de datos NewSQL y NoSQL

## Descripción

Este repositorio contiene los scripts y ejercicios prácticos desarrollados para la actividad académica sobre bases de datos NewSQL y NoSQL en entornos Big Data.

## Tecnologías utilizadas

- **CockroachDB:** ejercicios de creación de tablas, inserción de registros y consultas SQL.
- **MongoDB:** ejercicios de inserción, consulta y actualización de documentos.

## Organización del repositorio

Los archivos se encuentran organizados según la tecnología utilizada, NEWSQL y MongoDB.
